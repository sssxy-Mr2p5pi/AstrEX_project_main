# CartPole Step 3D：BalanceHold C 段验收

日期：2026-09-30。结论：6/6 个指定 Isaac 工况 PASS，均由节点在线返回 `SUCCESS`。独立日志分析确认每组连续稳定至少 3 仿真秒。本轮只完成 C 段，没有实现 MoveCart，没有重跑 B 段 17 组实验。

## 本轮实现

- `balance_hold_closed_loop_node.py` 只在新有效 `/joint_states` 到达时累计稳定时间。重复消息和控制定时器读取同一缓存都不累计。任一稳定条件失配，或反馈间隔超过 0.05 仿真秒，连续计时重新开始。
- 保留 B 段四项容差：位置误差 ≤0.05 m、速度绝对值 ≤0.10 m/s、杆角绝对值 ≤2°、角速度绝对值 ≤0.20 rad/s。非零初角还要求窗口内杆角小于初始值的 50%；5 cm 初位误差的恢复要求也保留。
- 连续稳定 3 秒后，节点停止控制循环、发送零命令并返回 `SUCCESS`。`result.json` 保存 `success_stamp_ns`、该帧 `success_state` 和 `stable_window`。不再以试验时间用完表示成功；到期仍未达标返回 `SIM_TIMEOUT`。
- boundary/reset、时间戳倒退、无效或陈旧状态、危险越界、非有限力、连续限幅和本地超时均先于成功检查。清零发布失败也不能返回成功。
- 删除旧矩阵专用的 ±2.1° 初角限制。初态仍须在配置的退出边界内；实际轨道范围继续由 Isaac 入口检查。初始化握手、单发布器、官方控制图和输出目录机制全部复用。
- 控制器限幅、发布限幅、状态失效、退出边界、连续限幅、试验期限和清零节拍均读取 `TrialConfig`。配置检查禁止放宽固定保护上限。

当前入口仍是有界试验节点，不是 ROS Action Server。它没有成功后的持续保持模式。

## 固定条件

Isaac 环境为 `isaaclab232_test`：Python 3.11.16、Sim 5.1.0.0、Torch 2.7.0+cu128、Lab v2.3.2 / `37ddf626871758333d6ed89cf64ad702aef127d0`。控制节点使用系统 ROS 2 Jazzy；ROS domain 为 63。

每组使用一个全新 headless Isaac 进程和一个 Cartpole，CPU PhysX、seed 42、dt=1/120 s。控制命令约 60 Hz；物理和状态反馈约 120 Hz。只推进底层 simulation 与 scene，不调用 `env.step(action)`。本轮没有改变 Q/R/K、模型、官方资产或环境包。

保护条件：发布力和 Isaac Controller 输入均不超过 ±5 N，摆杆 torque 为 0；退出角度 10°、相对保持位置偏移 0.25 m、连续限幅上限 0.5 仿真秒、状态本地失效阈值 0.2 秒。每组最多 10 仿真秒，另有 30 秒本地控制期限；每个 Isaac 进程最多 600 本地秒。仿真期限判定预留一个控制周期，避免终帧越过 10 秒。

## 结论与未覆盖范围

在本轮六个离散工况下，现有 LQR 在 5 N 限力内完成恢复，并由在线节点确认连续稳定 3 秒。±5° 没有失败，因此无需调整周期、初态或控制参数，也没有提高力上限。

本轮没有试验 ±8°、随机初速、更大角度、连续角度范围或长期保持，不能宣称整个 ±5° 状态区域均可恢复。Controller 输入仍不是 PhysX 实际 applied effort；后者为 N/A。清零只表示停止施力，不保证成功后的倒立摆无限保持直立。

C 段完成后可以设计移动参考。MoveCart、顺序 Runner 和自定义 ROS Actions 尚未在本轮实现，不能写成 PASS。
