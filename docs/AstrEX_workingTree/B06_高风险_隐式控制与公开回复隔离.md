# B06｜高风险｜隐式控制与公开回复隔离

作用：内部goal/参数/工具结果只进入AEB/EX，LLM可选择每步发言或完全静默。预计2–4人日。依赖B05。

## 1. 现状和目标

当前AEB `main.py::forward_reply()`提取普通文本并发 `interaction.reply`；EX `interaction_core.py::_handle_astrbot_reply_sync()`会发布文字并可能TTS。已有turn_id/generation与多段回复路由测试，但这些不等于完整隐私门禁。

新增AEB `output_router.py`；修改规划调用链和公开输出入口。EX对新任务公开消息验证 `visibility=user`、关联task/turn与有效generation。旧普通聊天兼容范围必须显式测试，不能让所有聊天静默。

## 2. 唯一公开出口

- AEB私有规划回合不注入普通用户事件自动回复链，模型原始文本不自动转发。
- 通过 `emit_user_message(text)`（建议工具名）明确生成公开消息；框架注入route_ref，不给模型任意填平台/用户ID。
- `finish_planning_turn(public_text=null)`是合法完成；若采用emit工具，finish不再发送第二份public_text，二选一协议在B00固定。**本包推荐emit工具+无文本finish。**
- 对普通闲聊仍使用AstrBot正常消息pipeline；同一条话不同时走工具发言和final自动回复。
- 日志、工具调用流、思考状态流和工具结果都不是用户正文。不能通过删除`<hidden>`标签来实现隔离。

## 3. 施工步骤与本步验收

| 步骤 | 工作 | 验收 |
|---|---|---|
| 1 | 明确private_planning和public_chat两类调用上下文 | 所有发送函数能判断来源；默认不明来源不公开任务内部文本 |
| 2 | 私有回合只执行受限工具；非流式或只消费不转发 | 内部JSON没有任何平台send/TTS调用 |
| 3 | 实现emit_user_message，继承会话路由、task/turn/generation | TTS或NapCat按配置选择，不默认双播 |
| 4 | 消息ID去重，与命令ID解耦 | 重发通知最多一次；通知失败不重发动作 |
| 5 | 旧goal/旧语音generation公开消息抑制 | 目标替代后不播“旧任务已完成” |
| 6 | 对话时机与执行事实对齐 | 未终态只能准备/尝试；完成宣告需事实关联 |
| 7 | 失败反馈默认内部，必要询问可公开 | 不把原始异常栈、JSON、密钥发用户 |
| 8 | 实际宿主/平台入口回归 | 普通聊天、分段回复、语音打断仍正常 |

安全急停告警可由预设策略强制通知，但不能携带内部敏感字段；它不意味着每个模型错误都必须打断用户。

## 4. 测试矩阵

新增 `test_output_isolation.py/test_public_output_router.py`；扩展AEB `test_plugin_channels.py`、EX `test_interaction_core.py/test_interaction_status.py`。

| ID | 场景 | 断言 |
|---|---|---|
| O01 | 仅goal/参数，无emit | send=0、TTS=0，动作链仍执行 |
| O02 | goal+一句公开话 | 一次公开输出；无JSON/工具结果 |
| O03 | 只澄清问题 | 公开输出一次；动作start=0 |
| O04 | 流式工具参数含“秘密标记” | 每个输出chunk均不含该标记 |
| O05 | 工具异常/LLM provider异常/空final | 不自动播原始异常或合成“已执行” |
| O06 | TTS失败/超时/重试 | 命令start计数仍=1 |
| O07 | 两会话交错、分段回复 | 路由不串，沿用原peer/turn |
| O08 | 目标替代或语音打断 | 旧generation文字/音频丢弃 |
| O09 | 正常非机器人聊天 | 回复正常，不受private规则误伤 |

通过：至少100次带唯一内部标记的随机组合场景，公开链路泄露=0；O01/O02/O03都成立；实际宿主测试无强制final播报。真NapCat账号/真TTS不可用时记未测，不能用mock结果宣称平台集成已完成。

## 5. 回滚

只关闭私有任务入口；不得回滚为“把内部JSON当普通回复”。任务仍活动时先停机。保留公开消息去重与隔离日志，不记录密钥或模型隐藏推理。
