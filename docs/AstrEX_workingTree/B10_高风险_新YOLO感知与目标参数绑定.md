# B10｜高风险｜新YOLO感知与目标参数绑定

作用：新建视觉插件，为LLM/Jev提供可信可追踪的检测JSON；LLM选定目标参数交给执行插件。预计4–7人日（不含专门训练、相机标定和长期视觉优化）。依赖B01/B02；任务端到端需B05。

## 1. 范围与新增文件

在 `D:\Code\EXplugin\vision\new_yolo` 建全新插件：manifest、main、配置、output_description、推理worker/协议、测试样例。目录名最终可调整，但action/topic一旦冻结要版本化。

不修改/复制废弃旧YOLO来假装新实现。参考的是现有EX SDK、ROS端口框架和B02动作接口，不是旧插件兼容负担。

推理路线：插件接收图像，独立worker执行选定YOLO模型，输出检测；图像源可为ROS2 Image或本地/回放源。具体模型包、weights、CPU/GPU/NPU支持和许可证在开工实测后锁定；本机和香橙派性能不能凭型号猜测。回放是测试后端，不是“真实YOLO已验收”的替代。

## 2. 数据与参数归属

- `new_yolo.detections`：原始检测JSON，不被LLM写回“选中”状态覆盖。
- LLM参数对象：引用一条真实观测、相机/追踪会话、frame_id、object_id，并标 `selected:true`；可附原bbox作为审计副本。
- 如UI希望显示选中框，生成独立 `target_selection` 派生视图，不篡改检测事实。
- Jev看感知JSON和说明；图片只给有视觉能力的LLM按需读取，不发给Jev。
- bbox坐标不是机械臂3D目标。实际pick插件必须要求深度/标定/变换或自己进行定位；缺失时返回参数不足，不能拿像素当米。

## 3. 插件能力

声明检测工作模式动作，如 `detect.start.v1/detect.pause.v1`，只有实现的操作才宣告。插件管理员enable与Jev选择开始检测分开。感知停止/健康失效要显式输出状态，不能继续把最后一帧当新帧。

## 4. 施工步骤及验收

| 步骤 | 工作 | 本步验收 |
|---|---|---|
| 1 | 确定输入源、推理设备和模型版本，记录许可证/weights hash | 有可重现安装配置；不运行下载来的任意脚本 |
| 2 | 实现受限worker启动/退出；图像/结果有界队列，保最新帧 | 推理慢不阻塞actor取消；不会无限积压图像 |
| 3 | 输出规范字段与小说明，每帧带可追踪ID和图像尺寸 | JSON与实际图像能一一对应 |
| 4 | 通过TopicBus供EX观测；按需接AEB JSON/JPEG缓冲 | JSON/JPEG的stream/frame对应，二者不能串帧 |
| 5 | 实现检测start/pause/cancel状态 | Jev经Dispatcher可调度，确认/失败经Ledger回报 |
| 6 | 参数绑定验证：框范围、目标存在、过期、追踪重启 | 旧参数不能直接落到新对象 |
| 7 | 加丢帧、无对象、坏图、worker崩溃/重启恢复 | 健康与空检测区分；不造出成功检测 |
| 8 | 在本机实际推理与香橙派部署各测性能/资源 | 记录实际FPS/延迟/内存，不沿用模型宣传值 |

若算法返回没有稳定track_id，则object_id只在该帧有效；之后执行必须重新定位或重选。不能用“bbox最近”未经验证跨帧绑定目标。

## 5. 测试与门槛

新增插件单元测试、EX `test_target_binding.py`、AEB视觉缓存关联测试。固定数据集含：单目标、多相似目标、遮挡、越界框、0检测、无深度、相机重启、目标移动。

| ID | 测试 | 通过标准 |
|---|---|---|
| V01 | 固定JSON回放与小说明 | 字段/坐标/单位解释一致，合法数据不变形 |
| V02 | LLM选择帧40对象8，执行前帧过期 | 拒绝/请求新参数，不能悄悄换成其他对象 |
| V03 | JSON和JPEG乱序、丢一侧 | 不错误配对；缺图明确提示 |
| V04 | 输入30FPS、推理慢于输入 | 队列受限，可丢旧图但不泄漏内存 |
| V05 | 推理worker卡住/退出 | actor仍能响应停止；观测标stale/unavailable |
| V06 | bbox-only驱动需要3D的pick | 零物理命令，返回missing_pose/depth/calibration |
| V07 | 真实模型固定图像集 | 有标注和实际检测报告；按冻结阈值判定，不要求浮点逐位一致 |

V07的类别范围和最低召回/误检阈值在开工锁定，未知相机/任务不虚构统一准确率。若尚未给出设备/数据集，只能签插件接口与回放通过，真实视觉效果待测。资源压力至少30分钟，记录峰值队列/RSS与失败恢复。

## 6. 回滚

停止检测动作、关闭worker、禁用新插件。禁止自动加载旧YOLO替代。目标引用失效必须传到AEB，不能保留一个“看起来仍选中”的旧框继续抓取。
