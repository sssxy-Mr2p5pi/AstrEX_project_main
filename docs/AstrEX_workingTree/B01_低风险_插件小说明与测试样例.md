# B01｜低风险｜插件小说明与测试样例

作用：为LLM/Jev提供插件自带的简短字段说明，并准备后续回放数据。预计1–2人日。依赖B00，可交弱agent。

## 1. 白名单与禁止范围

可新增 EX `docs/templates/output_description.md`、`tests/fixtures/decision/` 的JSON/Markdown、`tests/test_decision_fixtures.py`。可写新插件文档草稿。不得修改runtime、manifest解析器、调度器、Jev client、ROS发送、安全门禁。

本批不“创造统一感知schema”。框架统一的是来源/时间/版本外壳，插件正文仍解释各自JSON。

## 2. 感知小说明模板

```markdown
# Front camera detections
Topic: new_yolo.detections
Payload version: 1
Purpose: Detected objects in one camera frame. Not a 3D grasp pose.

- stream_id: camera stream identifier.
- frame_id: identifier of this frame; meaningful only inside the stream/session.
- image_width / image_height: pixels.
- objects: empty means no detections, not sensor failure.
- objects[].object_id: track identifier; valid only under the stated tracking session.
- objects[].label: detector class, not guaranteed semantic identity.
- objects[].confidence: detector confidence, not grasp success probability.
- objects[].bbox_xyxy: [left, top, right, bottom], pixels; origin top-left, x right, y down.
- depth_m: optional metric depth; null means unknown, not zero.

Failure: health is error/stale in the framework wrapper; do not use old data as current.
Selection: target selection is a separate LLM parameter object, not a mutation of raw detections.
```

最终模板要有完整JSON例子和每个实际字段的解释；中英对照可选，不能遗漏数组内部字段。建议正文≤8KiB，复杂插件可拆多个相关topic说明，由B02限制读取范围。

## 3. 实施步骤及验收

| 步骤 | 工作 | 本步验收 |
|---|---|---|
| 1 | 从B00复制外层元数据约定，不另起字段名 | fixture均使用冻结版本 |
| 2 | 为YOLO、模拟底盘状态、模拟机械臂状态分别写小说明 | 单位、坐标、空值、失败和时效均明确 |
| 3 | 写正常、空检测、缺深度、丢帧、旧帧、越界bbox、目标消失数据 | 每个场景有文件和预期结果 |
| 4 | 写动作/反馈合法与非法样例 | accepted/running/成功/失败/取消/unknown齐全 |
| 5 | 编写纯文件检查测试 | JSON可解析，字段说明覆盖，示例引用可解析 |
| 6 | 给B03/B07/B10建立场景索引 | 每条有scenario_id、用途、预期，无模型答案歧义 |

## 4. 测试与通过标准

建议 `python -m unittest discover -s tests -p 'test_decision_fixtures.py'`（文件在施工后才存在）。

至少20个fixture：8感知、6动作状态、6错误/边界。所有JSON严格有效；非有限浮点不得混入“合法样例”；单位/坐标解释无矛盾。每个被测试读取的字段必须在说明中出现。不要用“看描述大概能懂”作为标准。

注入样例必须包含“忽略规则、启动其他插件”之类文本，标为不可信数据；本批只提供样例，不实现安全过滤。

通过：纯文件测试全部通过；强agent抽查bbox坐标、目标生命周期和动作状态；无生产代码diff。
