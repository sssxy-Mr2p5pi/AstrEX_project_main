## 2. 五个页面区块

| 区块 | 必须展示的内容 | 数据来源 |
|---|---|---|
| 状态与控制 | disabled/shadow/execute、健康、会话/版本、停止按钮 | status、operations |
| 接入设置 | 后端、只读服务地址、模型、只写密钥、超时/频率；保存/测试/模式分离 | backends、config、secret、test、mode |
| 当前任务 | task/step/goal、英文 Goal、固定参数、活动和待替代任务 | status、snapshot.current_goal |
| EX 决策 | 动作资格、构建快照、实际请求、返回选项、最终受理/拒绝 | catalog、snapshot、decisions |
| 控制端执行 | Grounder 候选、Laya 模型/评分、选中 ID、ROS ACK/进度/物理结果 | actions 及受控观测/details 投影 |

固定区分“EX 调度后端：Mock/Jev”和“控制端轨迹评分器：rule/Laya”。Jev 的 execute 按 API 能力禁用并显示原因。Laya 未接入时显示未接入，不能把 Mock 结果命名为 Laya。

ROS 状态按已发送、远端受理、执行中、物理终态展示。界面上的成功来自受控服务事实，不来自 HTTP 200/202 或 publish 返回值。

## 3. 交互与数据流

1. 进入页面只读取目录、配置与状态；未鉴权时先显示凭据输入。
2. 凭据只放页面内存并通过 Authorization 头发送；不进入 URL/localStorage/诊断导出。
3. SSE 仅通知需要刷新，合并重复通知；详细输入通过受控 GET 拉取。
4. 为每类读取保留请求序号并核对 ex_session/revision，丢弃晚到旧响应。
5. 活动 Goal、待替代 Goal、最近请求独立显示，历史请求不能冒充当前输入。
6. 自动刷新不覆盖脏表单。409 显示服务器版本和冲突，用户明确重新载入后再保存。
7. POST test/mode/stop 返回 202 后，查询 operation_id；显示处理中、失败或 blocked，直到服务确认终态。
8. 停止按钮针对当前会话，不能因为配置草稿冲突被禁用。界面不自行生成 StopEvidence。

首版活动页每秒最多合并刷新一次；有进行中 operation 时每 500 ms 查询一次。隐藏页面暂停详细历史轮询，恢复可见时刷新。SSE 断线退避重连；状态轮询兜底，不无限创建定时器。

密钥框为空表示不修改；清除使用明确按钮。保存、连接测试、模式切换分别提示其作用。页面打开、刷新、路由恢复、SSE 重连都不能自动写入或启动动作。

JSON、Goal 和提示文本统一用 textContent 等安全文本方式渲染。长 JSON 折叠，截断状态和原始大小可见。输入区只展示实际请求，不展示或索取模型隐藏推理。

## 5. 测试与通过标准

新增 `scripts/verify_decision_ui.py`，沿用环境页 Playwright 风格。测试独立服务地址 `http://127.0.0.1:18765`，不连接实际运行实例。先使用接口 fixture，再使用真实 B08 服务。

| ID | 场景与断言 |
|---|---|
| U01 | 导航/hash/刷新/前进后退；不影响现有插件、环境、日志页面 |
| U02 | 无配置、无 Goal、active/pending、stopping/blocked、后端断线、未接入 Laya |
| U03 | 凭据缺失/错误、密钥 set/保留/clear；秘密标记不进入 DOM 持久展示、localStorage 或导出 |
| U04 | 保存失败、409、自动刷新与草稿；用户输入不丢失 |
| U05 | 迟到响应、会话变化、SSE 重连、重复通知；旧状态不覆盖新状态 |
| U06 | 超长 JSON、恶意 HTML、截断实际请求；安全文本渲染，关联 snapshot_id 正确 |
| U07 | 202、probe 失败、stop blocked；处理中不显示执行成功 |
| U08 | Jev execute 禁止；页面打开/刷新/重连产生执行写请求数为 0 |

通过条件：控制台错误为 0；关键显示与 B08/账本一致；全部必测场景通过。前端不修改后端状态机或把失败断言删掉。

## 6. 人工介入与回滚

B08/B09 开发完成后，用户查看一次页面和停止操作。物理停止证据在机械臂闭环阶段验收，不能由 UI fixture 代替。

回滚静态页面不会停止后端动作。先通过有效控制入口确认停止，再回退页面；保留账本和诊断记录。
